# Chrony

В Installer добавьте один экземпляр Chrony в «Топологии». Назначьте участникам
роли `server` или `client`. В «Сервисах» откройте настройки участников и укажите
разрешённые сети CIDR через запятую для серверной роли и адрес NTP-сервера для клиентской.
Для использования внешнего NTP-сервера можно разместить только клиентов.

Сервер раздаёт время по своим системным часам. Перед установкой выставьте
часы сервера и разрешите клиентам доступ к UDP/123 в сетевом экране. Клиент
подключается к заданному адресу. Verify проверяет состояние службы на всех
хостах и ожидает синхронизации с указанным источником только на клиентах.

## Standalone

Скопируйте `examples/inventory.yml` в рабочий inventory и замените адреса и
сети. Из корня репозитория на Ansible-контроллере выполните:

```sh
export ANSIBLE_COLLECTIONS_PATH="$PWD/services/chrony:$PWD/ansible-core/collections"
ansible-playbook -i ./inventory.yml services/chrony/playbooks/apply.yml
ansible-playbook -i ./inventory.yml services/chrony/playbooks/verify.yml
```

Для установки требуется RED OS 8, доступ к настроенным репозиториям либо
разрешённый офлайн-источник в плане Installer и повышение привилегий на целях.
Чужая конфигурация Chrony и другие активные службы времени требуют устранения
конфликта перед Apply.

Попробуйте макет

Измените образ или каждый порт отдельно, нажмите «В черновик», откройте Review. Работают сброс, поиск, секции, источники credentials и переход к библиотеке.

Что взято из Portainer

Образ в верхней части формы, таблица портов, отдельные секции запуска, environment и файлов. Настройки компактные, без универсального JSON-редактора на первом плане.

Существующая архитектура

Переиспользуются ApplicationsPage, формы bindings/credentials/files, edit-session amendment, общий Review/Save и существующий runtime lease. Размещение — у библиотеки. Запуск — на «Установка». Нового desired-state контракта нет.

Без неподдерживаемых возможностей

Нет прямых Start/Stop/Console, privileged, CPU/GPU или нового редактора произвольных volumes. Поля показываются только при наличии существующего контракта пакета.

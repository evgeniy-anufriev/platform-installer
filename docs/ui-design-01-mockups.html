Локальные настройки приложения

Безопасность

Runtime secrets и desired state не сохраняются в UI preferences.

Изменение сервера

Список типов загружает Go из application config. Тип — описательная метка и не выбирает сервисы, размещение или Execution Node. Сохраняется только ссылка на учётные данные; пароль или закрытый ключ в проект не записывается.

Экспорт проекта

Файл создаётся из portable desired state; пароль, ключи, факты и журналы в него не попадут.

Включается: inventory, group_vars, host_vars, catalog/artifact locks и поддерживаемые extension fields. Не включается: generated state, runtime workspace, plans, результаты и secret values.

Проверка read-only. Подготовка выполняется только после явного подтверждения и не изменяет топологию проекта.

Создать проект

Начнём с метаданных проекта. Inventory, host_vars и group_vars не создаются. Серверы, сервисы и размещение вы добавите самостоятельно.

Интерактивный макет: папка не создаётся, проверки файловой системы и вызовы backend не выполняются.

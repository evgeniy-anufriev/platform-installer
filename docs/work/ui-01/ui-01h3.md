# UI-01H3 — Member configuration and TLS-profile selection

Status: **DONE**

H3 completes the member-scoped configuration slice of the shared Services
editor. The member panel is derived from direct saved member placement plus
acknowledged typed placement intents, and every configuration target is the
canonical pair `(deploymentId, memberId)`. It adds no topology CRUD or second
save lifecycle.

Only the existing trusted `TLS_PROFILE` descriptor may show a profile selector.
Its options are stable IDs from managed TLS profiles plus the current typed PKI
draft; no certificate entities, SANs, secrets or Core-derived effective values
are rendered. Applying and resetting use the existing v1alpha8 member-scoped
Set/Remove commands, with the normal exact-target lock and common 16-command
limit.

The contextual **Manage certificates** action holds only application-local
deployment/member selection. It does not start a session or write state. Its
explicit return restores the same Services detail and member when still present
in the final typed draft; otherwise the Services list is restored safely.

# UI-01H2 — Services navigation and supported managed forms

Document scope: the original milestone contract/design. Historical status, review
and QA checkpoints are collected separately; current status and authorization
are recorded only in [CURRENT_STATE](../../../CURRENT_STATE.md).

Recorded status and review scope: [historical checkpoint](evidence/documentation-checkpoints-20261012.md#ui-01h2-checkpoint-002).

H2 delivers the global Services list/detail route and the single hand-off from
Topology. A selected deployment is configured through the same App-owned
EditSession, Review, Save and Discard lifecycle; no second deployment, session
or save path exists.

Only H1-safe deployment descriptors are editable: Boolean, bounded integer or
number, closed enum and bounded string. A setting is editable only with the
exact READY catalog, `MANAGED` ownership and deployment scope. TLS references,
member-only, advanced, protected, unsupported and unknown shapes remain
read-only. Unknown/unavailable catalog data exposes only stable setting ID and
override presence, never raw values or a secret input.

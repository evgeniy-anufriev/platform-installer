# UI-01E3 — shared runtime session credentials

Status: **DONE** (2026-09-14). UI-01E3 introduces one bounded, project-bound
runtime credential lease for the Servers page. It does not contact targets or
an Execution Node and does not write credential data to a portable project.

## Delivered boundary

- `internal/runtimesecret` owns one in-memory lease with 30-minute expiry,
  replacement, explicit clear and best-effort byte clearing.
- The lease accepts a technical username, SSH password or an unencrypted PEM
  RSA/ECDSA private key, plus an independent optional sudo password.
- Wails exposes only `SetSessionCredential`, `GetSessionCredentialStatus` and
  `ClearSessionCredential`. Status contains safe metadata only; it has no
  secret, key path or internal reference.
- `App.editMu` serializes credential and project lifecycle changes. Close,
  successful project replacement and application shutdown clear the lease;
  failed open preserves it.
- The compact Servers panel clears transient password/key-path form fields
  after a successful set. It is informational and does not block CRUD, review
  or commit.

The exact contract, scope exclusions and accepted PEM limitation are in
[the E3 architecture](ui-01e3-architecture.md). E4/E5 do not consume this
target credential; trusted remote transport remains UI-02 scope.

## Acceptance evidence

Windows automated gates passed:

```text
go test ./...
go vet ./...
frontend: npm run test -- --run     # 12 tests
frontend: npm run lint
wails build -nopackage -clean
```

The production Windows executable opened the existing local `ui-01c`
metadata-only project through the native folder dialog. On Servers, a
non-sensitive test credential produced a safe `Available until` status and
immediately cleared the password field; explicit Clear returned the visible
missing status. The project was not edited and no target or Execution Node was
contacted.

The affected concurrency package passed on RED OS with CGO:

```text
CGO_ENABLED=1 go test -race ./internal/runtimesecret
```

The source was copied with `scripts/qa-sync.ps1 -IncludeGo` to a fresh
`/var/tmp/platform-installer-qa-*` workspace and removed by the same helper.
`git diff --check` passed. No Core/service/Ansible regression was needed:
E3 changes only the desktop application runtime boundary.

# UI-01F6 — acceptance and regression evidence

Status: DONE. Date: 2026-09-16.

UI-01F6 adds no product behavior. It is the final acceptance and regression
slice for UI-01F1 through UI-01F5. UI-NET-01, UI-01G and UI-01H were not started.

## Mockup and boundary check

The acceptance checked the three agreed Topology presentations from
`docs/design/ui-design-01-mockups.html`: By services, By servers and Entry points.
Provider relation, virtual-router and virtual-address editing remain read-only
Core evidence and belong to UI-NET-01. The observed initial desktop screen permits
only project creation/open and keeps non-project navigation unavailable before
project context, as specified by the application-shell navigation gate.

## Windows desktop acceptance

`wails build -nopackage -clean` passed and produced
`build/bin/platform-installer-ui.exe`. The binary was opened and inspected: it
rendered the Project landing state, separate local-save/Core-verify explanation,
Create project and Open project actions, and disabled non-project navigation.
No project was created and no infrastructure action was invoked.

`npm run test:e2e --prefix frontend` passed (1 Playwright test), covering
automatic first eligible server selection and explicit Execution Node
replacement. The full frontend suite passed 38 tests, including catalog-driven
deployments, both placement forms, endpoint-group intents, INVALID preview
suppression and safe refresh states.

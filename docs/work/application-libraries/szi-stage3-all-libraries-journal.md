и подготовки (sequence7). UI мог проигнорировать поздно доставленное событие

использует отдельный порядок событий ACTION, независимо от порядка TASK.

только к листовым действиям. Core и последовательность установки не менялись.

текущего запуска с sequence0. Реальный UI восстановил «Подготовить ресурсы и
провайдеров — Выполняется»; процент0 сохраняется до подтверждённого завершения.

же Wails не подтверждает восстановление после перезапуска: текущий backend уже
знает этот run, поэтому сценарий требует другого сеанса. Эта проверка остаётся
незавершённой.

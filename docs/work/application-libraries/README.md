## Основания и границы

[Контракт проекта](../../project-contract.md), [Core](../../ansible-core.md) и
[архитектура](../../architecture.md) сохраняют силу. Общие проектные предложения
не отменяют versioned contracts подэтапов. Следующий scope требует разрешения
владельца. До UI реализации применяются [UI design](../../design/ui-design-01.md),
[mockups](../../design/ui-design-01-mockups.html) и соответствующий план.
